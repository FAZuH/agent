# Triage labels

Use this mapping when a skill names a canonical triage role.

| Canonical role | Tracker label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation is pending |
| `needs-info` | `needs-info` | Reporter information is pending |
| `ready-for-agent` | `ready-for-agent` | Fully specified for unattended agent work |
| `ready-for-human` | `ready-for-human` | Human implementation is required |
| `wontfix` | `wontfix` | The issue will not be implemented |

Use the tracker label column when applying or removing state labels.
